# 위치기반서비스 이용약관 - 보류

**언더스코어로 시작하는 폴더는 Next.js 가 라우트로 만들지 않는다.** 그래서 이 문서는
빌드에도 배포에도 나오지 않는다. 코드는 남겨 두고 공개만 미룬 상태다(2026-08-08).

## 왜 미뤘나

우리는 좌표를 서버로 보내지 않으므로(server ADR-0003) 위치정보를 **수집하지 않는다.**
그런데 **위치기반서비스 이용약관을 두는 것 자체가 LBS 사업자로 읽힐 수 있고**, 그렇다면
방송통신위원회 신고 의무가 따라온다. 신고에는 시간이 걸린다.

법률 검토 전까지 공개하지 않는다.

## 공개하려면

1. 폴더 이름에서 `_` 를 뗀다 (`_location` → `location`)
2. 랜딩(`(legal)/page.tsx`)의 `DOCUMENTS` 에 `/location` 을 되살린다
3. `/support` 의 문서 목록에도 추가한다
