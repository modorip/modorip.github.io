## 2. 디자인 토큰 요약

### 컬러

실값 정본은 `@seed-design/css`의 `--seed-*`다. 아래는 요약이고, 브랜드 축만 이 저장소가 재정의한다(`src/app/layout.tsx`, 근거는 [DESIGN.md](../DESIGN.md)).

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg.brand-solid` | `#0266FB` | 버튼·핀·마커 **바탕** |
| `fg.brand` | `#0250C5` | 브랜드 **글자·아이콘**, 활성 탭 |
| `bg.brand-weak` / `stroke.brand-weak` | `#EEF5FF` / `#BBD6FE` | 브랜드 약배경 / 경계 |
| `bg.layer-basement` | SEED | 캔버스 |
| `palette.static-white` | `#FFFFFF` | 카드 |
| `fg.neutral` / `fg.neutral-muted` | SEED | 본문 / 보조 |
| `stroke.neutral-muted` | SEED | 경계 |

바탕과 글자를 **다른 명도로 나눈다.** `#0266FB`는 흰 글자를 얹는 면적 요소(버튼 바탕)용이고(흰 글자 대비 4.89:1로 글자 크기와 무관하게 AA 통과), 짙은 `#0250C5`는 흰 배경에 얹는 글자·아이콘용이다(흰 배경 대비 7.10:1). 하나로 합치면 둘 중 하나가 반드시 대비 기준을 못 맞춘다.

### 4계열 컬러
자연 `#00882D` · 유적 `#AF6300` · 문화 `#6541F2` · 축제 `#CD2CB3`

계열마다 `color`(주색) / `soft`(약배경) / `dark`(강조) 3단이 있다. 정본은 `src/design/bundle.tsx`의 `CATEGORY_GROUPS`다.

### 17광역 식별색

광역마다 `tone`(채우기) · `dark`(글자) · `soft`(약배경) 3색. 4계열과 같은 구조다. 디자인 토큰이 아니라 **도메인 데이터**라 raw hex로 둔다(`` `${tone}33` `` 알파 문자열 연결 때문에 `var()` 불가). 정본은 `src/design/bundle.tsx`의 `REGIONS`.

색은 전부 그 지역에 실재하는 사물에서 왔다(한강 물빛·백제 자의·조치원 복숭아·전주 한지·빛고을·보성 차밭·신라 기와·남항 수심·한려수도 옥빛·감귤 등). 글자를 지는 `dark`는 흰 배경 5.34:1 이상·`soft` 위 4.71:1 이상이고, **`tone`에는 대비 하한을 두지 않는다** - 채움률은 % 숫자와 지역명이 같은 정보를 따로 전달하므로 색이 유일한 전달자가 아니다(WCAG 1.4.11 비적용).

> 2026-08-04 재확정값이고 코드 반영을 마쳤다. 값과 근거는 `../docs/03-디자인/디자인시스템.md`의 "17광역 식별색 - 확장" 절.

## 4. 화면별 레이아웃 설계

각 화면: **레이아웃 골격(위 → 아래) → 핵심 컴포넌트 → 주요 상호작용**.

### 00. 공통
- **하단 탭바**: 5탭, 활성 `fg.brand`(`#0250C5`) / 비활성 `fg.neutral-subtle`, 아이콘(home/compass/book-open/users/user)은 활성 시 `Line`↔`Fill` 스왑, 흰 배경 + 상단 1px 보더.
- **AppHeader**: subtitle(작은 회색) + title(굵게) + trailing 슬롯.
- **공통 컴포넌트**: Button(6변형) / Badge(9변형) / Chip / Avatar / IconButton / Card / ListRow / Progress / KoreaMap / RegionSilhouette.

### 01. 온보딩
- 골격: 풀스크린 5장 페이저 → 하단 dot indicator → 하단 CTA.
- 슬라이드: ①핀+동심원 ②3×3 타일 ③GPS pulse+버튼 ④5티어 뱃지 ⑤이름 입력.
- dot: 현재 22×6, 나머지 6×6. 우상단 "건너뛰기"(1–4), 5장 CTA "도감 시작하기".
- 상호작용: 스와이프/탭 이동, 이름 미입력 시 `꼬마탐험가`.

### 02. 홈
- 골격: 상단바(워드마크+검색/알림) → 인사+메인카피 → 통계 스트립(3) → 오늘의 추천(혼잡/한산 2칼럼) → 최근 발견(가로) → 빠른 진입(도감/발견) → 안 가본 지역(자동 슬라이드 4개).
- 통계 스트립 탭 → 도감. 추천 카드: 좌 danger/빨강, 우 success/초록 progress + API 출처.
- 안 가본 지역: 7초마다 4개씩, fade-up stagger 40ms, 우측 dot.

### 03. 발견 (GPS 지도)
- 골격: 상단 검색바(고정) → 지도 캔버스(한반도 SVG) → 우측 줌 컨트롤(9단계) → 중앙 현위치 마커 → 하단 바텀시트.
- 자원 핀 3상태: 미발견(흰+아이콘) / 발견(색+체크) / 선택(파란보더+GPS pulse+1.4×).
- 바텀시트: 사진+뱃지+이름+거리 → "여기에서 발견하기"(파랑) 또는 발견됨(초록).
- 줌 라벨 pill: 100m~50km, 기본 5km.

### 04. 발견 성공 (오버레이)
- 다크 배경 풀스크린 오버레이. 3단계 애니메이션:
  - Stage0(0–450) 스캔라인 / Stage1(450–1500) X축 720° flip / Stage2(1500+) spring 안착 + confetti 56.
- Stage2 콘텐츠: 카드(사진/뱃지/자원명/인덱스/시각) → 후기 남기기 버튼(누르면 입력창으로 전환) → 지역 진행률 "+1 → N/M" → CTA 닫기/도감에서 확인.

### 05. 도감 - 전국
- 골격: 헤더(서브 "전국 도감"/타이틀 "대한민국" + 지도/카드 토글) → 통계 스트립 → 지도 뷰(기본) → 선택 지역 카드.
- 지도 뷰: 17광역 폴리곤, 채움률 알파 0.36–0.92, 미발견 회색. 선택 시 1.14× + 검정 보더 + 글로우.
- 카드 뷰: 2열 그리드, 광역 실루엣(아래부터 차오름) + 풀네임 + N/M + % + progress.

### 06. 도감 - 광역 (`DexProvinceScreen`)
- 골격: 챕터 표지 300px → "어디로 갈까요?" 시트가 -72px 로 겹쳐 올라옴.
- 표지: `dark` 165deg 3-stop 그라데이션. 뒤로 / "N곳 발견" pill / 광역 약칭(t10) / catchphrase(`REGION_CATCHPHRASES`) / 진행 막대 3px = **방문한 시·군 비율**(자원 발견률이 아니다).
- 시트 블록 순서: 인기 자원(가로 레일, `popularPlaces(regionId, 8)` **8개 상한**, "모두 보기"→06B 광역 전체) → 코스 프리셋(3개까지, 초과 시 "모두 보기 · N"/"접기", 0개면 빈 상태) → 시군별로 보기("방문 N/M" + 시그니처 도시 칩 + "전체 N개 시·군 보기"→06C).
- 시그니처 도시 칩: 방문 우선 + 가나다 정렬. 방문 = `soft` 배경 + `tone` 실선 + `dark` 글자 + 발견 수, 미방문 = 회색 점선. 이름에서 `시`·`군` 접미사 제거.
- [주의] **계열별 진행 카드는 여기에 없다.** client 가 더한 블록이다.

### 06C. 도감 - 시·군 피커 (`DexSigunPickerScreen`)
- 골격: 헤더(뒤로 / "{광역} 시·군" / "N곳 · 방문 M" / 검색 TextField) → 2섹션 목록.
- 검색: 공백 제거 + 소문자 정규화 후 부분 일치. prefix 돋보기, 입력 시 지우기 버튼. 무결과 시 "'{검색어}'에 해당하는 시군이 없어요".
- 목록: "방문 중 · N곳" / "아직 가지 않은 곳 · N곳" 2섹션, 각각 가나다순. 행 = 점 인디케이터(방문 `tone` / 미방문 회색) + 이름 + `{발견}/{총계}`.
- [주의] **행의 `{발견}/{총계}` 는 `sigunsOf` 가 `hashStr` 로 지어낸 값이다.** client 는 이식하지 않았다. Flutter 이식에서 실제 수로 착각하지 마라.

### 06B. 도감 - 시군 상세 (`DexRegionScreen`)
- 골격: 헤더(`dark` 배경, 뒤로/실루엣 52px/눈썹/타이틀/N-M/진행바 6px, 우상단 "프리셋 만들기"[2곳+]) → 1차 계열 4버튼(단일, **기본 `nature`**) → 2차 카테고리 칩(가로, 다중) → 필터 pill(전체 N/발견 N/미발견 N) → 자원 그리드(2열).
- 눈썹·타이틀: 시·군이 있으면 "{광역} · 시군 도감" + 시·군명, 없으면 "지역 도감" + 광역 정식명(접미사 제거).
- 자원 카드: 미발견(grayscale+0.78, 실제 이름 노출) / 발견(컬러+success 뱃지+"내 사진"). 좌상단 인덱스 `#001`. 빈 조건이면 "해당 조건의 자원이 없어요."
- [주의] **시·군을 골라도 헤더 카운트는 광역 전체 수다.** 시·군 단위로 셀 수단이 없다.

### 07. 장소 상세
- 골격: 헤로 320px(사진/실루엣, 탭→3D카드, 좌 뒤로/우 하트, 우하단 발견·내사진 뱃지, 좌하단 KTO코드) → 본문(radius 24, 음수마진 겹침).
- 본문 순서: ①헤더(뱃지/자원명/메타 + 카카오 길찾기 노란원) ②내 사진 카드 ③설명 카드(머무는시간/희귀도/시즌) ④30일 혼잡도 캘린더(한산/보통/혼잡 3색, 오늘 강조) ⑤자원 정보(주소/전화/시간+공식페이지) ⑥반경 5km 주변(식당/카페/숙박) ⑦CTA(발견됨 초록 / 미발견 "여기로 떠나기" 파랑).

### 08. 3D 카드 모달
- 다크 백드롭(blur 12) 풀스크린. 상단 좌 앞/뒷면 pill, 우 X. 카드 280×392, 탭 시 flip(rotateY, 700ms).
- 앞면: 사진 60% + 인덱스/뱃지 + 자원명/카테고리/지역 + 발견일/희귀도/시즌.
- 뒷면: "모두립 도감 카드"+KTO코드 / 4계열 아이콘+"당신은 N번째 발견자" / "N명이 담음" / 지역핀+"모두립·2026".
- 홀로그래픽: radial shine + 스펙트럼 stripes + inset highlight. 하단 힌트.

### 09. 광장
- 골격: 세그먼티드 4탭(피드/인기 프리셋/리더보드/동행) → 탭별 본문.
  - **피드**: 카드(아바타+이름+다양성뱃지 / 지역·시간 / 사진 / 자원명+발견뱃지 / 응원·댓글·가는법).
  - **인기 프리셋**: 검색 input → 태그 칩(빈도순, 다중) → 카드 그리드(savedCount 내림차순, Top3 메달). 카드: 실루엣+제목+"N곳·N회"+미리보기5+작성자.
  - **리더보드**: 헤더(이번 달 발견왕, 다양성↔발견수 토글) → Top3 포디움(2/1/3) → 4–9위 리스트("나" 강조).
  - **동행**: 비-산 카드3 / 산악(노란 안전안내+카드2+안전태그). 모집 CTA 점선 카드.

### 10. 칭호 (5티어)
- 골격: 통계 카드(획득 N/전체 M + 대표 변경) → 티어 범례(가로 5) → 티어별 카드 그룹.
- 5티어: 입문 / 광역 / 카테고리 / 표고 / 마스터.
- 카드: 획득(티어색 강조) / 진행중(회색+progress+N/M).

### 11. 프로필
- 골격: 다크 히어로("나의 발견"+설정 / 아바타+이름+활성칭호 pill / 통계3) → 빠른 링크 ListRow(칭호/가고싶다/여행기록/협력혜택/언어/데모초기화) → 4계열 진행 카드 → 내 프리셋 / 담은 코스 → 푸터 워드마크.
- 프리셋 빈 상태: "아직 등록한 코스가 없어요".

### 12. 프리셋 - 만들기
- 진입: 도감 지역상세 → "프리셋 만들기"(2곳+ 발견 시).
- 골격: 헤더(뒤로 / "{지역} 프리셋 만들기") → 기본정보(이름 필수/설명) → 태그(최대6, 추천 점선칩6) → 자원 선택(헤더 우측 인라인 검색 160px + 후보 그리드) → 코스 순서(1,2,3 번호, 위/아래/X) → 하단 CTA "등록".
- 비활성 조건: 이름 빈칸 또는 자원 0개 → 등록 disabled.

### 13. 프리셋 - 상세
- 골격: 지역 톤 헤로(뒤로/실루엣/제목/"N곳·N회") → 작성자 카드(탭→타유저) → 설명 → 태그(subtle) → 코스 순서(리스트/지도 토글) → CTA.
  - 리스트 뷰: 번호 자원 카드(탭→장소상세).
  - 지도 뷰: 광역 폴리곤 + 번호 핀 + 파란 점선 경로.
- CTA: 본인(없음) / 타인 미담음("내 프리셋에 가져오기" 파랑) / 담음("담았어요" 초록 토글).

### 14. 타 유저 프로필
- 골격: 다크 히어로(뒤로/설정 / xl 아바타+이름 / 통계3) → 수집 칭호(가로 8) → 수집 도감(2×3 슬라이드, 7초 자동회전) → 미발견 지역(컴팩트 칩) → 등록한 프리셋.
- collected 0: 미발견 칩만. 프리셋 0: "아직 공유한 코스가 없어요".
